# Job & Housing Comparison

A Python learning project for comparing jobs and housing using salary, rent,
commute time, and transportation expenses.

## Current progress

Project setup. Stage 1 will introduce the `Job` and `Housing` classes and simple
calculation helpers using hardcoded examples.

## Local setup (Windows / PowerShell)

Python 3.14 is currently used for development. No third-party packages are needed yet.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe --version
```

In VS Code, open this folder and use **Python: Select Interpreter** from the
Command Palette to select `.venv\Scripts\python.exe`.
Using the virtual environment's Python directly does not require activation.
